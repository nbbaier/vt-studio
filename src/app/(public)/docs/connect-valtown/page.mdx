<DocContent title="Connect to Val Town" group="Connecting">

Outerbase Studio is purpose-built for managing Val Town SQLite databases with an intuitive, browser-based interface.

Connecting to your Val Town personal database is simple. Follow these steps:

## Generate API Token

1. Go to [Val Town API Token Settings](https://www.val.town/settings/api)
2. Click **"New"** to generate a new API token
3. Copy the token to your clipboard

## Connect to Your Database

1. Open Outerbase Studio
2. Click **"New Connection"** and select **"Val Town"**
3. Paste your Val Town API token
4. Click **"Connect"**

Your connection will be saved locally in your browser for easy access.

## Managing Your Data

Once connected, you can:

- Browse and edit tables
- Write and execute SQL queries
- Design schemas visually
- Create triggers and views
- Export data in various formats
