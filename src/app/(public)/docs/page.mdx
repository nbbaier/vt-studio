<DocContent title="Outerbase Studio for Val Town" group="About">

Outerbase Studio is a powerful and lightweight SQLite database GUI built specifically for Val Town. It runs entirely in your browser and provides seamless integration with Val Town's SQLite API.

**Key Features:**

- **Powerful Data Editor** - Handle thousands of rows and columns efficiently with an optimized table renderer.
- **SQL Query Editor** - Syntax highlighting, SQLite-specific tooltips, and auto-completion tailored for Val Town databases.
- **Schema Management** - Visual tools for editing table schemas, indexes, triggers, and views.
- **Val Town Integration** - Simple authentication with Val Town API tokens, secure local storage of connections.

This version is optimized exclusively for Val Town SQLite databases, providing the best possible experience for managing your Val Town data.
